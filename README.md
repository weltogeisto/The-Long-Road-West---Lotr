# The Long Road West

**An Interactive Atlas of the Elven Migrations in Arda**

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![React](https://img.shields.io/badge/React-18+-61DAFB.svg)

An interactive, animated visualization of the great Elven migrations across Tolkien's Arda—from the Awakening at Cuiviénen through the sailing of the last ship from the Grey Havens.

## ✨ Features

- **Authentic Arda Geography** — Hand-drawn SVG landmasses based on Karen Wynn Fonstad's *Atlas of Middle-earth*
- **Dynamic Timeline** — Watch history unfold across the Ages:
  - Years of the Trees
  - First Age (including the sinking of Beleriand)
  - Second Age (rise and fall of Númenor)
  - Third Age (the Fading and final departure)
- **Animated Migration Paths** — Glowing trails show the journeys of each Elven kindred
- **Tolkien Cartographic Style** — Parchment tones, serif typography, mountain ridges, decorative flourishes
- **Interactive Controls** — Pan, zoom, timeline scrubbing, chapter navigation

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/the-long-road-west.git
cd the-long-road-west

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🎨 Design Philosophy

This project aims to capture the scholarly, cartographic aesthetic of Tolkien's own maps and the comprehensive atlas work of Karen Wynn Fonstad. Key design decisions:

- **Parchment palette** — Warm tans and creams for land, deep blues for sea
- **Serif typography** — Palatino Linotype for an antiquarian feel
- **Hand-drawn mountains** — Ridgeline symbols rather than terrain shading
- **Subtle animations** — Glowing paths and pulsing markers, not flashy effects
- **Eight-pointed stars** — The Elven star motif for key locations

## 📜 Lore Accuracy

Geography and migration paths are based on:
- *The Silmarillion* (J.R.R. Tolkien)
- *The Atlas of Middle-earth* (Karen Wynn Fonstad)
- *The History of Middle-earth* series
- Tolkien's own maps and letters

Note: Some simplifications were made for visual clarity.
